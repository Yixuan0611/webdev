# 🎬 DRAMS — Drama Recommendation Website

> 🎓 My first project for the **Web Development** module in school — built entirely with HTML, CSS, and vanilla JavaScript.

DRAMS is a drama discovery website where you can explore must-watch English, Chinese, and Korean dramas — and even submit your own recommendations. It was designed as a personal passion project around something I genuinely enjoy: dramas!

---

## ✨ What is DRAMS?

DRAMS is a multi-page static website that acts as a mini drama catalogue. Whether you're looking for your next binge-worthy series or want to share a hidden gem with others, DRAMS has you covered.

The site features:
- 🏠 A **home page** with a looping video hero banner and top drama picks across three languages
- 📺 Dedicated pages for **English**, **Chinese**, and **Korean** dramas with cover art and details
- 🔗 Quick links to popular **streaming platforms** — Netflix, iQIYI, Viu, Disney+, and Amazon Prime
- 📝 A **recommendation form** where visitors can submit their own drama picks, complete with genre tags, airing status, and a star rating
- ✅ A **confirmation page** that displays the submitted recommendation back to the user

---

## 🖥️ Pages at a Glance

| Page | What it does |
|------|-------------|
| `index.html` | Home — video banner, top picks, streaming platform links |
| `Edrama.html` | English drama catalogue |
| `Cdrama.html` | Chinese drama catalogue |
| `Kdrama.html` | Korean drama catalogue |
| `Reco.html` | Submit a drama recommendation |
| `Reco2.html` | Confirmation page showing your submitted recommendation |

## 🛠️ Built With

This project was built from scratch using only the fundamentals — no frameworks, no libraries, no shortcuts.

- **HTML5** — page structure, forms, embedded video
- **CSS3** — layout with flexbox, responsive design, custom styling per page
- **JavaScript (Vanilla)** — interactive star rating, hamburger menu toggle, form handling via URL query parameters
- **[Boxicons]** — star icons for the rating widget
- **[Google Fonts]** — Comic Neue & Open Sans
